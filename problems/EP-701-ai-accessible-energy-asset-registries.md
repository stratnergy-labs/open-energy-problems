# AI-Accessible Energy Asset Registries

> **Stub.** This card states a label, not yet a problem. It needs a problem statement, a definition of done and a baseline before it can leave `stub`. Start from the [problem-card template](../templates/problem-card-template.md).

## Problem

Make official energy asset registries queryable by AI systems in a structured, safe, reproducible way.

## Why It Matters

Asset registries are core evidence for grid, market, and planning questions.
AI-facing access can be useful only if provenance, query limits, source
timestamps, licences, and result caveats are explicit.

## Scope

Registry connectors need rate limits, provenance, licence handling, and result hashing.

## Existing Artefacts

Related contribution IDs are listed in front matter. Source URLs and licence details require human verification before claims are upgraded.
